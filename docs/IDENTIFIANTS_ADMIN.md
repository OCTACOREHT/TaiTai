# Identifiants Administrateur - TaiTai Restaurant

## Accès Administration

**Email:** `taitai@gmail.com`  
**Mot de passe:** À définir par le client lors de la première connexion

## Première Connexion

1. Ouvrez le navigateur et accédez à l'interface d'administration
2. Utilisez l'email ci-dessus
3. Le mot de passe par défaut est vide ou prédéfini
4. **Important:** Changez le mot de passe immédiatement après la première connexion via la page "Équipe"

## Changer le Mot de Passe

1. Connectez-vous en tant qu'administrateur
2. Allez dans la page **"Équipe"**
3. Cliquez sur le bouton **"Mot de passe"** à côté de votre compte "TaïTaï Admin"
4. Saisissez le nouveau mot de passe
5. Cliquez sur **"Enregistrer"**

## Gestion de l'Équipe

Depuis la page "Équipe", vous pouvez:
- Ajouter de nouveaux membres d'équipe (admin ou caissier)
- Réinitialiser le mot de passe des membres
- Supprimer des comptes (sauf le compte propriétaire)

## Rôles Disponibles

- **Administrateur principal (super_admin):** Accès complet à toutes les fonctionnalités
- **Administrateur (admin):** Accès complet à toutes les fonctionnalités
- **Caissier:** Accès limité aux commandes, validation et menu

## Support

Pour toute question, contactez l'équipe technique.
